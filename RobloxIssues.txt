# Roblox Issues Tracking Document

## Global Function Access Problems (⚠️ HIGH PRIORITY)

**Error Message:** Multiple "attempt to call a nil value" errors when trying to access _G functions.

**Context:** Observed when trying to run automation scripts in the Studio console.

**Impact:** High. Prevents developers from running automation scripts needed for model processing.

**Frequency:** Consistent when calling any _G functions.

**Specific Errors:**
- `_G.AutomateGym():1: attempt to call a nil value`
- `_G.AutomateAllGyms():1: attempt to call a nil value`
- `_G.ProcessEquipment():1: attempt to call a nil value`
- `_G.BatchProcessModels():1: attempt to call a nil value`

**Status:** 
- ❌ Despite log showing GYM TYCOON AUTOMATION LOADED, none of the global functions are available
- ❌ Log shows "Failed to load server core modules - GymAutomation functionality will be limited"
- ❌ SafeWait timeout when attempting to load server core modules: "SafeWait: Timed out waiting for server in ServerScriptService"

**Recommended Next Steps:**
1. Fix GymAutomation module to properly expose global functions
2. Ensure server core modules are loaded before GymAutomation initializes
3. Implement proper error handling in GymAutomation to show helpful diagnostic messages
4. Create a fallback system for automation functions that don't require core modules

**Context:** Observed when the game starts, affecting multiple critical systems and UI components.

**Impact:** High. Prevents proper initialization of UI and game systems.

- `Infinite yield possible on 'ServerScriptService.Core:WaitForChild("TutorialManager")'`

- `Infinite yield possible on 'ReplicatedStorage:WaitForChild("PlaySoundEvent")'`
- `Infinite yield possible on 'Players.Xdjpearsonx.PlayerScripts:WaitForChild("Core")'`
- `Infinite yield possible on 'ReplicatedStorage.shared:WaitForChild("ClientRegistry")'`
