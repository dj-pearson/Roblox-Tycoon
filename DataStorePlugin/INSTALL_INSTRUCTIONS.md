# DataStore Manager Pro - Installation Instructions

## Method 1: Manual Installation through Studio

1. **Open Roblox Studio**
2. **Go to Plugins menu** → **Manage Plugins**
3. **Click "Install from file..."**
4. **Select either:**
   - `DataStoreManagerPro-Fixed.rbxmx`
   - `DataStoreManagerPro-Plugin.rbxmx`
5. **Click Install**

## Method 2: Toolbox Installation (Alternative)

1. **Open Roblox Studio**
2. **Go to View** → **Toolbox**
3. **Click "Plugins" tab**
4. **Click the "+" icon to add from file**
5. **Select the plugin file**

## Method 3: Direct File Installation

1. **Copy plugin file to:**
   ```
   %LOCALAPPDATA%\Roblox\Plugins\DataStoreManagerPro.rbxm
   ```
2. **Restart Roblox Studio completely**
3. **Look for "DataStore Manager" button in toolbar**

## Troubleshooting

If the plugin doesn't appear:
- Try restarting Studio 2-3 times
- Check if the plugin file is corrupted (should be around 7KB)
- Try renaming the file (remove any "user_" prefix)
- Ensure Studio has proper permissions to load plugins

## Expected Output

When working correctly, you should see:
```

Plugin type check: Plugin
Running in plugin context: true
Toolbar created successfully: ...
Button created successfully: ...
```
