## CoreRegistry

The CoreRegistry is the central system that provides access to all consolidated modules.

### Accessing Modules

```lua
local ServerScriptService = game:GetService("ServerScriptService")
local CoreRegistry = require(ServerScriptService.server.Core.CoreRegistry)

-- Get any registered system
local EquipmentManager = CoreRegistry:GetSystem("EquipmentManager")
```

### Available Methods

| Method | Description |
|--------|-------------|
| `CoreRegistry:RegisterSystem(name, system)` | Registers a system with the registry |
| `CoreRegistry:GetSystem(name)` | Returns the specified system |
| `CoreRegistry:HasSystem(name)` | Checks if a system is registered |
| `CoreRegistry:RemoveSystem(name)` | Removes a system from the registry |
| `CoreRegistry:RegisterLegacySystem(name, system)` | Registers a legacy system for backward compatibility |
| `CoreRegistry:GetLegacySystem(name)` | Returns a registered legacy system |

## EquipmentManager
<a id="equipmentmanager"></a>

The EquipmentManager handles all aspects of gym equipment including setup, attributes, pricing, and upgrades.

### Equipment Detection & Categorization

#### `EquipmentManager:DetectEquipmentCategory(model)`
Determines the equipment category based on model name and attributes.

**Parameters:**
- `model` (Instance): The equipment model to categorize

**Returns:**
- `string`: The detected category ("CARDIO", "STRENGTH", "AMENITIES", "SPECIALTY", or "STRUCTURE")

**Example:**
```lua
local category = EquipmentManager:DetectEquipmentCategory(treadmill)
print("Treadmill category:", category) --> "CARDIO"
```

#### `EquipmentManager:DetectEquipmentType(model)`
Detects the specific equipment type based on name and visual appearance.

**Parameters:**
- `model` (Instance): The equipment model to analyze

**Returns:**
- `string`: The detected equipment type

**Example:**
```lua
local equipType = EquipmentManager:DetectEquipmentType(treadmill)
print("Equipment type:", equipType) --> "treadmill"
```

#### `EquipmentManager:GetEquipmentFloor(model)`
Determines which floor the equipment is on.

**Parameters:**
- `model` (Instance): The equipment model

**Returns:**
- `number`: The floor number (starting from 1)

**Example:**
```lua
local floor = EquipmentManager:GetEquipmentFloor(benchPress)
print("Bench press is on floor:", floor)
```

### Equipment Setup & Attributes

#### `EquipmentManager:ExtractEquipmentAttributes(model)`
Extracts and generates attributes for an equipment model.

**Parameters:**
- `model` (Instance): The equipment model

**Returns:**
- `table`: A table of attribute key-value pairs

**Example:**
```lua
local attributes = EquipmentManager:ExtractEquipmentAttributes(treadmill)
print("Price:", attributes.Price)
print("Income boost:", attributes.IncomeBoost)
```

#### `EquipmentManager:SetupEquipmentAttributes(model)`
Sets up all attributes for an equipment model and caches the data.

**Parameters:**
- `model` (Instance): The equipment model

**Returns:**
- `table`: The applied attributes

**Example:**
```lua
EquipmentManager:SetupEquipmentAttributes(treadmill)
print("Price set:", treadmill:GetAttribute("Price"))
```

#### `EquipmentManager:CalculateEquipmentPrice(attrs)`
Calculates the price for equipment based on its attributes.

**Parameters:**
- `attrs` (table): Equipment attributes including Category, Floor, and UpgradeLevel

**Returns:**
- `number`: The calculated price

**Example:**
```lua
local price = EquipmentManager:CalculateEquipmentPrice({
    Category = "CARDIO",
    Floor = 2,
    UpgradeLevel = 1
})
print("Calculated price:", price)
```

#### `EquipmentManager:CalculateEquipmentIncome(attrs)`
Calculates the income generated by equipment based on its attributes.

**Parameters:**
- `attrs` (table): Equipment attributes including Category, Floor, and UpgradeLevel

**Returns:**
- `number`: The calculated income amount

**Example:**
```lua
local income = EquipmentManager:CalculateEquipmentIncome({
    Category = "STRENGTH",
    Floor = 1,
    UpgradeLevel = 2
})
print("Calculated income:", income)
```

### Equipment Upgrades

#### `EquipmentManager:GetNextUpgradeInfo(model)`
Gets information about the next upgrade for a piece of equipment.

**Parameters:**
- `model` (Instance): The equipment model

**Returns:**
- `table` or `nil`: Upgrade information including level, name, price, and income changes

**Example:**
```lua
local upgrade = EquipmentManager:GetNextUpgradeInfo(treadmill)
if upgrade then
    print("Next level:", upgrade.level)
    print("Upgrade name:", upgrade.name)
    print("Price:", upgrade.price)
    print("New income:", upgrade.newIncome)
    print("Income increase:", upgrade.incomeIncrease)
end
```

#### `EquipmentManager:UpgradeEquipment(model)`
Applies an upgrade to a piece of equipment.

**Parameters:**
- `model` (Instance): The equipment model to upgrade

**Returns:**
- `boolean`: Success or failure of the upgrade

**Example:**
```lua
local success = EquipmentManager:UpgradeEquipment(treadmill)
if success then
    print("Upgraded to level:", treadmill:GetAttribute("UpgradeLevel"))
else
    print("Already at max level or upgrade failed")
end
```

#### `EquipmentManager:SetEquipmentLevel(model, level)`
Sets a specific upgrade level for equipment.

**Parameters:**
- `model` (Instance): The equipment model
- `level` (number): The level to set (1-5)

**Returns:**
- `boolean`: Success or failure

**Example:**
```lua
EquipmentManager:SetEquipmentLevel(treadmill, 3)
```

### Equipment Processing

#### `EquipmentManager:ProcessEquipment(model, options)`
Processes a single piece of equipment, setting up attributes and interactions.

**Parameters:**
- `model` (Instance): The equipment model
- `options` (table, optional): Configuration options
  - `setupAttributes` (boolean, default: true): Whether to set up attributes
  - `generateInteractions` (boolean, default: true): Whether to create interaction boxes

**Returns:**
- `table`: The applied attributes

**Example:**
```lua
local attrs = EquipmentManager:ProcessEquipment(treadmill, {
    setupAttributes = true,
    generateInteractions = true
})
```

#### `EquipmentManager:ProcessAllEquipment(folder, options)`
Processes all equipment within a folder recursively.

**Parameters:**
- `folder` (Instance): The folder containing equipment
- `options` (table, optional): Same options as ProcessEquipment

**Returns:**
- `table`: Statistics about processed equipment

**Example:**
```lua
local stats = EquipmentManager:ProcessAllEquipment(workspace.Tycoon)
print("Processed:", stats.processed, "Skipped:", stats.skipped)
```

### Global Studio Functions

The following global functions are available in Studio for testing:

- `_G.ProcessEquipment(options)`: Process all equipment in workspace
- `_G.UpgradeEquipment(model)`: Upgrade a specific piece of equipment
- `_G.GetUpgradeInfo(model)`: Get upgrade information for equipment

## BoundingBoxManager
<a id="boundingboxmanager"></a>

The BoundingBoxManager handles bounding boxes and hitboxes for tiles and equipment.

### Core Functionality

#### `BoundingBoxManager:CalculateBoundingBox(instanceOrParts)`
Calculates a bounding box for a model or collection of parts.

**Parameters:**
- `instanceOrParts` (Instance or table): The model or collection of parts

**Returns:**
- `table`: Bounding box with CFrame and Size properties

**Example:**
```lua
local bbox = BoundingBoxManager:CalculateBoundingBox(model)
print("Size:", bbox.Size)
```

#### `BoundingBoxManager:GetPadding(model, padding)`
Gets padding values for a model based on its type and attributes.

**Parameters:**
- `model` (Instance): The model
- `padding` (number, optional): Default padding value

**Returns:**
- `table`: Padding values for each direction (top, bottom, left, right)

**Example:**
```lua
local padding = BoundingBoxManager:GetPadding(tile, 0.2)
```

### Hitbox Creation

#### `BoundingBoxManager:CreateHitbox(instance, options)`
Creates a hitbox for a model or part.

**Parameters:**
- `instance` (Instance): The model or part
- `options` (table, optional): Configuration options
  - `color` (Color3, optional): Hitbox color
  - `transparency` (number, optional): Hitbox transparency
  - `padding` (number or table, optional): Padding around hitbox
  - `hitboxType` (string, optional): Type of hitbox ("buy", "interact")

**Returns:**
- `Instance`: The created hitbox part

**Example:**
```lua
local hitbox = BoundingBoxManager:CreateHitbox(tile, {
    color = Color3.fromRGB(255, 0, 0),
    transparency = 0.8,
    padding = 0.2,
    hitboxType = "buy"
})
```

#### `BoundingBoxManager:CreateTileHitbox(tile, options)`
Creates a hitbox specifically for a tile, with buy-tile attributes.

**Parameters:**
- `tile` (Instance): The tile model or part
- `options` (table, optional): Configuration options (same as CreateHitbox)

**Returns:**
- `Instance`: The created hitbox part

**Example:**
```lua
local hitbox = BoundingBoxManager:CreateTileHitbox(tile)
```

#### `BoundingBoxManager:CreateInteractionBox(model, options)`
Creates an interaction hitbox for a model.

**Parameters:**
- `model` (Instance): The model
- `options` (table, optional): Configuration options
  - `interactionType` (string, optional): Type of interaction ("use", "upgrade", etc)
  - `actionText` (string, optional): Text to display for interaction
  - Other options from CreateHitbox

**Returns:**
- `Instance`: The created interaction hitbox

**Example:**
```lua
local interactionBox = BoundingBoxManager:CreateInteractionBox(treadmill, {
    interactionType = "use",
    actionText = "Use Treadmill"
})
```

#### `BoundingBoxManager:CreateEquipmentInteractionBox(equipment, options)`
Creates an interaction box specifically for gym equipment.

**Parameters:**
- `equipment` (Instance): The equipment model
- `options` (table, optional): Configuration options (same as CreateInteractionBox)

**Returns:**
- `Instance`: The created interaction hitbox

**Example:**
```lua
local interactionBox = BoundingBoxManager:CreateEquipmentInteractionBox(treadmill)
```

### Hitbox Management

#### `BoundingBoxManager:GetHitboxForTile(tile)`
Finds the hitbox associated with a tile.

**Parameters:**
- `tile` (Instance): The tile to find a hitbox for

**Returns:**
- `Instance` or `nil`: The found hitbox or nil if not found

**Example:**
```lua
local hitbox = BoundingBoxManager:GetHitboxForTile(tile)
```

#### `BoundingBoxManager:GetInteractionBoxForEquipment(equipment)`
Finds the interaction box associated with a piece of equipment.

**Parameters:**
- `equipment` (Instance): The equipment model

**Returns:**
- `Instance` or `nil`: The found interaction box or nil if not found

**Example:**
```lua
local interactionBox = BoundingBoxManager:GetInteractionBoxForEquipment(treadmill)
```

#### `BoundingBoxManager:SetHitboxesVisible(visible)`
Sets whether all hitboxes are visible or not.

**Parameters:**
- `visible` (boolean): Whether to show hitboxes

**Returns:**
- `table`: Statistics about affected hitboxes

**Example:**
```lua
BoundingBoxManager:SetHitboxesVisible(true) -- Show hitboxes
```

#### `BoundingBoxManager:HighlightHitbox(hitbox)`
Temporarily highlights a hitbox.

**Parameters:**
- `hitbox` (Instance): The hitbox to highlight

**Returns:**
- `boolean`: Success or failure

**Example:**
```lua
BoundingBoxManager:HighlightHitbox(hitbox)
```

#### `BoundingBoxManager:CleanupHitboxes()`
Removes orphaned or invalid hitboxes.

**Returns:**
- `table`: Cleanup statistics

**Example:**
```lua
local result = BoundingBoxManager:CleanupHitboxes()
print("Removed hitboxes:", result.removed)
```

## BuyTileProgressionManager
<a id="buytileprogresionmanager"></a>

The BuyTileProgressionManager handles tycoon progression, build order, and prerequisites.

### Build Order Management

#### `BuyTileProgressionManager:GetBuildOrder(tycoon)`
Gets the recommended build order for a tycoon.

**Parameters:**
- `tycoon` (Instance): The tycoon model

**Returns:**
- `table`: Array of tile IDs in recommended build order

**Example:**
```lua
local buildOrder = BuyTileProgressionManager:GetBuildOrder(tycoon)
for i, tileInfo in ipairs(buildOrder) do
    print(i, tileInfo.id)
end
```

#### `BuyTileProgressionManager:RegisterBuildStep(tycoon, tileId, prerequisites, priority)`
Registers a build step in the progression.

**Parameters:**
- `tycoon` (Instance): The tycoon model
- `tileId` (string): The ID of the tile
- `prerequisites` (table): Array of prerequisite tile IDs
- `priority` (number, optional): Priority level (higher = earlier in build order)

**Returns:**
- `boolean`: Success or failure

**Example:**
```lua
BuyTileProgressionManager:RegisterBuildStep(tycoon, "ReceptionDesk", {}, 100)
BuyTileProgressionManager:RegisterBuildStep(tycoon, "Treadmill1", {"ReceptionDesk"}, 90)
```

### Prerequisite Management

#### `BuyTileProgressionManager:GetTilePrerequisites(tile)`
Gets the prerequisites for a specific tile.

**Parameters:**
- `tile` (Instance): The tile to check

**Returns:**
- `table`: Array of prerequisite tile IDs

**Example:**
```lua
local prereqs = BuyTileProgressionManager:GetTilePrerequisites(tile)
for _, prereqId in ipairs(prereqs) do
    print("Required:", prereqId)
end
```

#### `BuyTileProgressionManager:SetTilePrerequisites(tile, prerequisites)`
Sets prerequisites for a tile.

**Parameters:**
- `tile` (Instance): The tile to set prerequisites for
- `prerequisites` (table): Array of prerequisite tile IDs

**Returns:**
- `boolean`: Success or failure

**Example:**
```lua
BuyTileProgressionManager:SetTilePrerequisites(swimPool, {"ReceptionDesk", "ChangingRoom"})
```

#### `BuyTileProgressionManager:IsTileUnlockable(tile)`
Checks if all prerequisites are met for a tile.

**Parameters:**
- `tile` (Instance): The tile to check

**Returns:**
- `boolean`: Whether the tile can be unlocked

**Example:**
```lua
if BuyTileProgressionManager:IsTileUnlockable(tile) then
    print("Tile can be purchased!")
end
```

### Floor Progression

#### `BuyTileProgressionManager:GetFloorPrerequisites(floor)`
Gets prerequisites for unlocking a floor.

**Parameters:**
- `floor` (Instance): The floor model

**Returns:**
- `table`: Array of prerequisite tile IDs

**Example:**
```lua
local prereqs = BuyTileProgressionManager:GetFloorPrerequisites(floor2)
```

#### `BuyTileProgressionManager:SetFloorPrerequisites(floor, prerequisites)`
Sets prerequisites for unlocking a floor.

**Parameters:**
- `floor` (Instance): The floor model
- `prerequisites` (table): Array of prerequisite tile IDs

**Returns:**
- `boolean`: Success or failure

**Example:**
```lua
BuyTileProgressionManager:SetFloorPrerequisites(floor2, {"ReceptionDesk", "Treadmill1", "BenchPress1"})
```

#### `BuyTileProgressionManager:IsFloorUnlockable(floor)`
Checks if all prerequisites are met for a floor.

**Parameters:**
- `floor` (Instance): The floor to check

**Returns:**
- `boolean`: Whether the floor can be unlocked

**Example:**
```lua
if BuyTileProgressionManager:IsFloorUnlockable(floor2) then
    print("Floor 2 can be unlocked!")
end
```

### Validation and Integration

#### `BuyTileProgressionManager:ValidateBuildOrder(tycoon)`
Checks if the current build order has any circular dependencies or other issues.

**Parameters:**
- `tycoon` (Instance): The tycoon model

**Returns:**
- `table`: Validation results with any issues found

**Example:**
```lua
local validation = BuyTileProgressionManager:ValidateBuildOrder(tycoon)
if validation.valid then
    print("Build order is valid!")
else
    print("Issues found:", validation.issues)
end
```

## TileDataGenerator
<a id="tiledatagenerator"></a>

The TileDataGenerator handles creation and management of tile data.

### Tile Data Generation

#### `TileDataGenerator:GenerateTileData(model, options)`
Generates complete tile data for a model.

**Parameters:**
- `model` (Instance): The model to generate data for
- `options` (table, optional): Configuration options
  - `category` (string, optional): Tile category
  - `floor` (number, optional): Floor number
  - `useModelNameAsTileType` (boolean, optional): Whether to use the model name as the tile type

**Returns:**
- `table`: Generated tile data

**Example:**
```lua
local tileData = TileDataGenerator:GenerateTileData(model, {
    category = "Equipment",
    floor = 2
})
```

#### `TileDataGenerator:ExtractModelAttributes(model)`
Extracts existing attributes from a model.

**Parameters:**
- `model` (Instance): The model to extract attributes from

**Returns:**
- `table`: Extracted attributes

**Example:**
```lua
local attributes = TileDataGenerator:ExtractModelAttributes(model)
```

#### `TileDataGenerator:ApplyTemplateToModel(model, templateName)`
Applies a predefined template to a model.

**Parameters:**
- `model` (Instance): The model to apply the template to
- `templateName` (string): Name of the template to apply

**Returns:**
- `table`: The applied attributes

**Example:**
```lua
TileDataGenerator:ApplyTemplateToModel(model, "treadmill")
```

### Template Management

#### `TileDataGenerator:RegisterTemplate(templateName, attributes)`
Registers a new template for future use.

**Parameters:**
- `templateName` (string): The template name
- `attributes` (table): The attributes for the template

**Returns:**
- `boolean`: Success or failure

**Example:**
```lua
TileDataGenerator:RegisterTemplate("squat_rack", {
    Category = "STRENGTH",
    Price = 1200,
    IncomeBoost = 60,
    InteractionType = "use",
    ActionText = "Use Squat Rack",
    UsageTime = 120
})
```

#### `TileDataGenerator:GetTemplate(templateName)`
Gets a registered template.

**Parameters:**
- `templateName` (string): The template name

**Returns:**
- `table`: The template attributes or nil if not found

**Example:**
```lua
local template = TileDataGenerator:GetTemplate("treadmill")
```

### Tile Identification

#### `TileDataGenerator:GenerateTileId(model)`
Generates a unique ID for a tile based on its properties.

**Parameters:**
- `model` (Instance): The model

**Returns:**
- `string`: The generated ID

**Example:**
```lua
local tileId = TileDataGenerator:GenerateTileId(model)
```

## MigrationUtils
<a id="migrationutils"></a>

The MigrationUtils module provides utilities for migrating data between old and new formats.

### Data Migration

#### `MigrationUtils.MigrateEquipmentData(oldFormat, newFormat)`
Migrates equipment data from old format to new format.

**Parameters:**
- `oldFormat` (table): The equipment data in old format
- `newFormat` (table, optional): Pre-initialized table for new format

**Returns:**
- `table`: The equipment data in new format

**Example:**
```lua
local newData = MigrationUtils.MigrateEquipmentData(oldEquipmentData)
```

#### `MigrationUtils.MigrateTileData(oldFormat, newFormat)`
Migrates tile purchase data from old format to new format.

**Parameters:**
- `oldFormat` (table): The tile data in old format
- `newFormat` (table, optional): Pre-initialized table for new format

**Returns:**
- `table`: The tile data in new format

**Example:**
```lua
local newData = MigrationUtils.MigrateTileData(oldTileData)
```

#### `MigrationUtils.MigrateProgressionData(oldFormat, newFormat)`
Migrates progression data from old format to new format.

**Parameters:**
- `oldFormat` (table): The progression data in old format
- `newFormat` (table, optional): Pre-initialized table for new format

**Returns:**
- `table`: The progression data in new format

**Example:**
```lua
local newData = MigrationUtils.MigrateProgressionData(oldProgressionData)
```

### Data Validation

#### `MigrationUtils.ValidateEquipmentData(data)`
Validates equipment data structure and logs issues.

**Parameters:**
- `data` (table): The equipment data to validate

**Returns:**
- `boolean`: Whether the data is valid

**Example:**
```lua
if MigrationUtils.ValidateEquipmentData(equipmentData) then
    print("Equipment data is valid")
else
    print("Issues found in equipment data")
end
```

#### `MigrationUtils.ValidateTileData(data)`
Validates tile data structure and logs issues.

**Parameters:**
- `data` (table): The tile data to validate

**Returns:**
- `boolean`: Whether the data is valid

**Example:**
```lua
MigrationUtils.ValidateTileData(tileData)
```

#### `MigrationUtils.ValidateProgressionData(data)`
Validates progression data structure and logs issues.

**Parameters:**
- `data` (table): The progression data to validate

**Returns:**
- `boolean`: Whether the data is valid

**Example:**
```lua
MigrationUtils.ValidateProgressionData(progressionData)
```

### Rollback Functions

#### `MigrationUtils.RollbackMigration(dataType)`
Rolls back to original data if migration fails.

**Parameters:**
- `dataType` (string): The type of data to roll back ("equipment", "tiles", "progression")

**Returns:**
- `table`: The original data

**Example:**
```lua
local originalData = MigrationUtils.RollbackMigration("equipment")
```

#### `MigrationUtils.ClearOriginalData(dataType)`
Clears stored original data to free memory.

**Parameters:**
- `dataType` (string, optional): The type of data to clear, or nil to clear all

**Returns:**
- None

**Example:**
```lua
MigrationUtils.ClearOriginalData("tiles")
```

## Testing Tools

These global functions are available in Studio to help test and validate the system:

### Test Suite

- `_G.RunTestSuite()`: Runs comprehensive tests for all modules
- `_G.ValidateTycoons()`: Validates all tycoons in the workspace
- `_G.ShowBuildOrder()`: Visualizes the build order for a tycoon
- `_G.ShowTileProgression(tile)`: Visualizes progression for a specific tile
- `_G.ShowFloorProgression()`: Visualizes floor unlocking progression
- `_G.RunMigrationTests()`: Tests data migration functionality

### Deprecation Tracking

- `_G.GetDeprecationTelemetry()`: Gets usage statistics for deprecated functions
- `_G.ConfigureDeprecation({...})`: Configures deprecation notice behavior
- `_G.GenerateDeprecationHeader(oldScriptName, newModuleName, description)`: Generates a deprecation header for a script
